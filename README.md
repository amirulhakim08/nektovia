# nektovia.com

Laman web statik untuk NEKTOVIA — The Golden Trio (RM49).

- `index.html` — laman utama
- `assets/css/style.css`, `assets/js/main.js`
- `assets/img/` — gambar (WebP)

## Tetapan
Tetapkan nombor WhatsApp dalam `assets/js/main.js` (`WHATSAPP_NUMBER`, cth. `60123456789`).

## Deploy
Tiada build. Muat naik folder ini ke GitHub Pages / Netlify / Vercel / cPanel. Fail `CNAME` sudah ditetapkan untuk `nektovia.com` (GitHub Pages).
